# Лабораторна робота №3 — класи й об'єкти для опису об'єкта керування

**Варіант №9:** система зрошення сільськогосподарських угідь (C#, .NET 8).

```
AutomatedIrrigationSystem.sln
└── AutomatedIrrigationSystem/
    ├── Enums.cs                          ValveState, PumpState, FertigationState
    ├── Sensors/
    │   ├── Sensor.cs                     абстрактний базовий клас датчика
    │   ├── SoilMoistureSensor.cs         датчик вологості ґрунту
    │   ├── PressureSensor.cs             датчик тиску в магістралі
    │   ├── AirTemperatureSensor.cs       датчик температури повітря
    │   └── RainSensor.cs                 датчик опадів
    ├── Actuators/
    │   ├── IrrigationValve.cs            електромагнітний клапан зони
    │   ├── WaterPump.cs                  насосна станція (з аварійною зупинкою)
    │   └── FertigationSystem.cs          система фертигації (дозування добрив)
    ├── Controllers/
    │   └── IrrigationController.cs       контролер зрошення
    └── Program.cs                        демонстрація роботи
```

## Логіка контролера

1. Насос в аварії — керування заблоковано до скидання оператором.
2. Тиск під час роботи насоса поза межами 1.5…6.0 бар — аварійна зупинка.
3. Йде дощ (> 0.5 мм/год) — полив відкладається.
4. Спека (≥ 30 °C) — нижній поріг вологості підвищується з 30 % до 40 %.
5. Вологість нижче порогу — насос, клапан і фертигація вмикаються; 70 % і вище — вимикаються.

## Запуск

```bash
dotnet run --project AutomatedIrrigationSystem
```
