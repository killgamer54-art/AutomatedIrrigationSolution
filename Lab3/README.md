# Лабораторна робота №3 — класи й об'єкти для опису об'єкта керування

**Варіант №9:** система зрошення сільськогосподарських угідь (C#, .NET 8).

```
AutomatedIrrigationSystem.sln
└── AutomatedIrrigationSystem/
    ├── Enums.cs                          ValveState, PumpState
    ├── Sensors/
    │   ├── SoilMoistureSensor.cs         датчик вологості ґрунту
    │   └── PressureSensor.cs             датчик тиску в магістралі
    ├── Actuators/
    │   ├── IrrigationValve.cs            електромагнітний клапан зони
    │   └── WaterPump.cs                  насосна станція
    ├── Controllers/
    │   └── IrrigationController.cs       контролер зрошення (логіка з порогами)
    └── Program.cs                        демонстрація роботи
```

## Запуск

```bash
dotnet run --project AutomatedIrrigationSystem
```
