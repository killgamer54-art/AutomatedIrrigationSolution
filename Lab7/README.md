# Лабораторна робота №7 — відображення поточного часу, дати та календаря у вебінтерфейсі SCADA-системи

**Варіант №9:** система зрошення сільськогосподарських угідь.
**Виконав:** студент гр. ІКМ-М726а Шкурат К. Ю.

ASP.NET Core MVC (.NET 8), MQTTnet. Рішення продовжує вебпроєкт SCADA з лабораторної роботи №6 (папка `Lab6`).

## Склад рішення

| Проєкт | Призначення |
|---|---|
| `IrrigationScada.Components` | Бібліотека класів: `SensorReading`, MQTT-теми датчиків |
| `IrrigationScada.Simulator` | Симулятор об'єкта: публікує показання в MQTT кожні 2 с |
| `IrrigationScada.Web` | SCADA-вебзастосунок: мнемосхема, годинник, календар |

## Зміни лабораторної роботи №7

Нові файли не створювались, `_LoginPartial.cshtml` не змінювався.

| Файл | Зміна |
|---|---|
| `Views/Shared/_Layout.cshtml` | Блок годинника `.scada-clock` (час і дата українською, формуються сервером через `DateTime.Now`) перед `<partial name="_LoginPartial" />`; вміст сторінки в `div.container-fluid`; скрипт `setInterval` для щосекундного оновлення годинника без перезавантаження |
| `Views/Scheme/Index.cshtml` | Мнемосхема і таблиця календаря поточного місяця обгорнуті в контейнер `.scada-page`; зсув першого дня `((int)first.DayOfWeek + 6) % 7`, перенесення рядка після неділі, класи `today` і `weekend` |
| `wwwroot/css/site.css` | Стилі `.scada-clock`, `.scada-page`, `.cal` (сьогодні — зелений `#4a7a5a`, вихідні — червоний `#c0392b`) |

## Запуск

1. Запустити MQTT-брокер Mosquitto на `127.0.0.1:1883`.
2. Запустити `IrrigationScada.Simulator` і `IrrigationScada.Web` (Multiple startup projects, F5).
3. Відкрити «Мнемосхема»: у шапці праворуч — годинник і дата, праворуч від схеми — календар.

## Обмеження реалізації

- Після завантаження сторінки час береться з комп'ютера оператора, а не із сервера.
- Календар не оновлюється автоматично після півночі (потрібно оновити сторінку).
- Логіка календаря розміщена безпосередньо в представленні (доцільно винести у ViewModel або ViewComponent).
